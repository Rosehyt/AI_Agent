AI-powered Search Engine

"Morphic is an AI-powered search engine with a generative UI that allows users to interact with various AI models through a unified chat interface.

Morphic provides a flexible chat interface that connects to multiple AI providers (like OpenAI, Anthropic, Google AI) and search engines (such as Tavily, SearXNG, Exa). It uses a streaming architecture to deliver real-time responses with integrated search capabilities, allowing AI models to retrieve and present up-to-date information from the web. [...] Morphic is built on Next.js with a modular architecture that separates concerns between the UI layer, API endpoints, AI integration, and search functionality.
